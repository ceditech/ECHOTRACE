# Guide for a possible later owner submission

For a separately authorized review, choose existing documents that identify the asset and establish a relevant use or a missing source link.

- License agreements, written grants and commercial or derivative-use authorizations can establish proposed use scope when their issuer and applicability are supported.
- Purchase receipts are useful with the applicable terms and exact item identifier. Acquisition records, creator ownership or assignment records can help establish source and authority.
- Original artwork and reference provenance records can link active inputs to the scene. Character-reference permission records can address Mara and Owen's specific reference and derivative uses.
- Generation-service terms already held by the owner are useful with the applicable version, effective date, service and generation context.
- Existing font raster-use terms can help assess the numbered stand workflow. Identify the record for Arial Bold raster output and keep font-file embedding, redistribution and modification questions distinct. Leave the font binary outside scope.

Different assets can require different forms of proof. For any future record, identify the request ID, asset ID, exact file or version, original source, issuer, terms version and intended use. Include conditions and attribution, with omissions identified explicitly. Use the same record reference for several assets where applicability is supported. A receipt or provenance record can establish only the facts it documents.
