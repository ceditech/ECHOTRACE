# Conditional first review batch

If the owner later supplies a suitable bundle and authorizes access, ER-P0-01 is a useful first review. Background and backpack are stable material inputs with direct paths and hashes in the audit. Linked acquisition and permission records would let a reviewer practice the full match from issuer and item to exact file, proposed game use and inherited composite scope. One complete asset record is a useful initial unit if only one is available.

| Potential batch | Value | Condition |
|---|---|---|
| Background and backpack acquisition and permission records | Tests an exact source match and a direct inherited-rights dependency | Begin with one or both complete linked records if actually supplied |
| Generation-service terms | Can clarify output-use scope across several generated assets | Prefer this alternative if a dated terms version and relevant generation context are more complete |
| Original source or reference permission | Can resolve an important input dependency for a prop or character | Start with one exact material reference and its applicable grant if linkage is clear |

The suggested order reflects ease of matching rather than predicted rights outcomes. The owner would select the actual records and scope in a separate authorization. This proposal records no execution selection or document availability. [Dependency analysis](RIGHTS_DEPENDENCY_AND_REMAINING_GAPS.md)
