# Facilitator-only protocol

Recruit three consenting first-time viewers unfamiliar with Case 001. Use anonymous P1/P2/P3 identifiers. Assign P1 desktop (960 CSS px), P2 320 CSS px, P3 390 CSS px. Randomize their session order where practical (shuffle three slips); record actual order. Do not show prior concepts, original screenshots, answers or this protocol to participants.

Only trial 1 per participant counts as first-time evidence. Later widths are familiarized legibility trials and must be logged separately. With one fresh viewer per width, this is a qualitative smoke test; it cannot establish robust recognition rates or device comparisons.

1. Record device, browser/version, viewport, browser zoom, OS scaling, device pixel ratio, visual viewport scale and scene width. Confirm adequate viewport, no cropping, no unexpected overlays. Finish facilitator-only browser preflight first.
2. Open the participant screen and confirm both images have preloaded (ready). Read the exact neutral instruction in TEST_SCRIPT.md.
3. Start; the original is displayed for 25 seconds without countdown or hints.
4. It is completely hidden for a neutral 2-second blank. Keep silence.
5. The changed scene alone appears. Ask “What changed?” immediately; measure response latency from changed-scene onset, not from the end of the question. Record any question delay.
6. Allow up to 60 seconds of unprompted responses. Record verbatim statements and elapsed times; say nothing about objects, locations or completeness. End recall when the participant finishes, or let the automatic 60-second cutoff hide the image.
7. Lock independent scoring before any follow-up: timestamp the lock in the sheet. Do not revise independent scores from prompted answers.
8. Ask post-lock recognition/character questions. These may direct attention and therefore carry no independent credit. Record uncertainty, confusion and distraction separately.
9. If desired, Reset for another width, identifying the trial as familiarized. No zoom/highlights/arrows/annotation or back navigation is allowed during original/recall.

If image loading fails, the screen is hidden/resized, a browser stalls, the participant sees the original again, or facilitation supplies a hint, flag the trial invalid and explain why. A restart is not fresh evidence; recruit another unfamiliar viewer for replacement evidence. Record actual exposure durations if observed rather than assuming browser timers were exact.

Human tests and real-device tests have not been performed by the package author. Interactive runtime/touch testing is outside authorization.
