# Minimum remaining rights work

1. Identify the exact background and backpack origins, then the material prop and character references. Start with the active Mara sheet, paired concept and earlier pose lineage, and share evidence for repeated inputs.
2. Tie the recorded AI generation to actual service, account type or governing agreement, and approximate generation period sufficient to determine the applicable terms. Group assets where a shared generation context is supported. Review another provider if one is identified on a material path.
3. Confirm applicable raster-output terms for the Arial Bold numeral workflow. Scope this to the rendered pixels.
4. Map the exact pair to one coverage schedule for upstream input use, derivative editing, raster embedding, and intended commercial distribution. Document the evidence for each material dependency and refer only residual ambiguity to qualified review.

An existing generation record, applicable agreement, creator authority record or focused owner clarification may answer different parts of the inquiry. Ask for a receipt only where a claimed acquisition is relevant. A deterministic crop, number rasterization or contrast edit does not create a separate stock acquisition event. Apply the [D05-B review preparation](../owner-held-rights-review-preparation/README.md) if the owner separately authorizes evidence submission and review.
