# Rights dependency map

| Upstream evidence | Downstream review affected | Verification support |
|---|---|---|
| P0-01 background/backpack and P0-02 prop/material references | B0 and the exact CCV pair, with passport and stand inputs inherited by C1a and C2a | P1-02 matches acquisition and source IDs. P1-01 helps link generated intermediates to repository files. |
| P0-03 Mara sheet and P0-04 Owen concept/pose/style | Both cutouts, A13 static layer, B0 and CCV | P1-03 maps active reference versions. Reuse the Mara sheet grant where applicable to Owen style use. |
| P0-05 recorded Arial Bold raster use | Both numbered stands, C2a and composite numerals | P1-04 improves identity and entitlement matching using records. |
| P0-06 applicable generation-service terms | Relevant generated prop, reference and character outputs and their derivatives | P1-01 matches outputs and generation context. Match shared terms to each covered generation. |
| P0-07 inherited scope and any required supplemental grants | A13–A17 coverage of the exact proposed production use | Each applicable upstream permission or reasoned applicability finding feeds this review. |
| P2-01 path index | Navigation only | Independent, with no effect on permission completeness. |

P0-01 through P0-06 can be prepared independently where their source records are held separately. Character style linkage and shared generation terms require cross-references. P1 rows identify related workstreams. Those links describe matching support and shared sources, so they need not be treated as a strict execution order. P0-07 may be indexed early. Its substantive completeness depends on the applicable upstream review.

The smallest useful later review package is one asset-linked record bundle with actual applicable terms or permission, issuer authority and version, exact source mapping, proposed uses and restrictions, and a list of omissions. It can resolve a single request item or enable an applicability review. A full adoption review needs coverage of all material inputs and inherited uses for both exact CCV files. No probability, deadline or resource commitment is assigned.

Conflicting issuer claims, uncertain service-version applicability, font raster scope, and unclear derivative or distribution language can require qualified review. An unsuitable or unavailable grant calls for an explicit owner decision to hold or consider a separately scoped replacement strategy. A change of asset, intended use, or production authority also requires a new scope decision.
