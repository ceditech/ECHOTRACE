# Engineering implementation — Layer A

[Projection](../../../../src/game/application/neutral-scene.ts) resolves validated observationSceneId, preserves visual order and copied identity/normalized center/size/rotation, rejects missing/same snapshots, unknown/duplicate objects and invalid geometry. ID-derived labels expose development identities rather than narrative descriptions. Application retains Original only. Generic Changed projection exists for tests, not a player toggle. [Integration tests](../../../../tests/integration/neutral-observation.test.ts) compare authored arrays and exactly three meaningful changes: passport removal, stand exchange, closed wallet movement. Four differing IDs represent three events because the stand pair is one exchange. This does not validate character art/staging.

[Briefing](../../../../src/game/application/briefing.ts) owns session handoff: Start→intro, matching ready→active; phase/loading/attempt/revision guard outcomes. Retry keeps attempt and increments revision. Existing domain commands validate timestamps/transitions. No observation scheduler, score or persistence is added. Existing loader timeout is not an observation countdown.

[Host](../../../../src/game/renderer/phaser-host.tsx) captures request identity for the keyed mount, imports runtime lazily and owns one resize observer. [Runtime](../../../../src/game/renderer/phaser-runtime.ts) maps normalized geometry to960×540 FIT/CENTER_BOTH, drawing geometry first and labels last with rotated upper-edge anchors. No observation interactive handlers. POST_RENDER once reports readiness after construction; destroyed/event-removal guards suppress late callbacks. Source and mocks support ordering; Chrome did not measure actual frame/callback ordering or pre-ready exposure.

[Lifecycle](../../../../src/game/renderer/shell-lifecycle.ts) separates import/init failure, cancels delayed work, disconnects resize and destroys runtime. Host disposes [bridge](../../../../src/game/application/renderer-bridge.ts); runtime immediately detaches canvas and requests Phaser destruction. Source/tests plus observed zero/one canvas cycles support lifecycle acceptance, not memory-leak certification.

[Experience](../../../../src/game/presentation/case-experience.tsx) supplies native controls, focus and status/alert. N03 compact observation CSS applies at sm widths/max-height600; canonical geometry and briefing layout unchanged. SSR tests check scoping; real browser measurements establish960×540 fit. No new demonstrated critical source defect. Full artwork loading, visual fairness and universal accessibility remain outside this technical result.
